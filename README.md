# Solitaire Lab

学園アイドルマスターの「ソリティア」（1ターンの中の札・ドリンクの使い方）を、確率を正確に扱って計算し、
目標点に届く確率が最も高く、ドリンクや操作が少ない手順を示す、**非公式のファンツール**です。**営利目的ではありません**。

**使い方：** このリポジトリの GitHub Pages の URL をブラウザ（PC 推奨）で開くだけです。インストールは要りません。

1. **デッキ**：札・ドリンク・P アイテムを名前（略称でも可）で探して登録します。
2. **局面**：札を押すかドラッグして、手札・保留・捨て札・除外に振り分けます（山札は自動）。数値を入れます。
3. **結果**：次の手、達成率・期待ドリンク・期待操作、答えの種類（最適（証明済み）／暫定）が出ます。
4. **プレイ**：引いた札を選ぶと、次の手を案内します。

## 大切なこと
- 計算はすべて、使う人のブラウザの中で行います。入力したデッキや局面は、そのブラウザの中だけに保存され、どこにも送りません。
- 1ターンの中だけを計算します。ターン開始時の効果は、起きた後の値を初期条件として入力します。体力・元気・全力は省きます。札の効果は gakumas-tools のデータの文面どおりで、一部は実際のゲームとの照合がまだです。
- 答えは計算のモデルに基づくもので、実際のゲームの結果を保証するものではありません。
- ゲーム「学園アイドルマスター」の権利者、および gakumas-tools とは関係がなく、公認を受けたものではありません。
